SITE PROVITRES-64 — nettoyage-vitres-bayonne.fr
================================================

Ce dossier contient le site complet (HTML/CSS/JS), prêt à être mis en ligne.
Les adresses des pages sont IDENTIQUES à celles du site Squarespace :
aucune perte de référencement.

------------------------------------------------
ÉTAPE 1 — Déposer le site sur GitHub (5 min)
------------------------------------------------
1. Va sur github.com > « New repository » > nom : provitres64-site > « Create repository ».
2. Clique sur « uploading an existing file ».
3. Glisse TOUT le contenu de ce dossier (pas le dossier lui-même) :
   index.html, les fichiers .html, le dossier assets, le dossier blog-actus,
   _redirects, _headers, netlify.toml, sitemap.xml, robots.txt, favicon.ico, 404.html.
4. Clique sur « Commit changes ».

------------------------------------------------
ÉTAPE 2 — Mettre en ligne sur Netlify (5 min)
------------------------------------------------
1. Sur netlify.com > « Add new site » > « Import an existing project » > GitHub.
2. Choisis le dépôt provitres64-site. Laisse la commande de build VIDE, dossier de publication : « . ».
3. « Deploy ». Le site est visible sur une adresse provisoire du type xxx.netlify.app.
   → Ton site Squarespace reste en ligne pendant ce temps : zéro risque.
4. Vérifie les pages sur l'adresse provisoire.

------------------------------------------------
ÉTAPE 3 — Formulaire de contact
------------------------------------------------
Le formulaire utilise Netlify Forms (rien à installer).
Netlify > ton site > « Forms » > « Form notifications » > ajoute
contact@nettoyage-vitres-bayonne.fr pour recevoir chaque demande de devis par email.

------------------------------------------------
ÉTAPE 4 — Bascule du nom de domaine (le jour J)
------------------------------------------------
1. Netlify > « Domain management » > « Add a domain » > www.nettoyage-vitres-bayonne.fr.
2. Chez ton registrar (là où le domaine est acheté), remplace les enregistrements DNS
   de Squarespace par ceux indiqués par Netlify.
3. Netlify active le HTTPS automatiquement.
4. Google Search Console > Sitemaps > soumettre : sitemap.xml
5. Garde l'abonnement Squarespace 1 mois de plus par sécurité, puis résilie.
